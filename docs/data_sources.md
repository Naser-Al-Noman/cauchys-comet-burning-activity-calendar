# Planned data sources

This list reflects datasets we **plan** to use for Cauchy's Comet. We have not yet ingested or published any of this data in the repository.

## Active fire detections

- **NASA FIRMS** archived active-fire products:
  - **MODIS** on Terra and Aqua
  - **VIIRS** on Suomi-NPP, NOAA-20, and NOAA-21

These archives will be the primary input for hot-spot harmonization and calendar metrics.

## Validation and context

- **MODIS MCD64A1** — burned-area product for independent comparison with detection-based metrics (where overlap is appropriate).
- **NASA POWER** — meteorological context (for example, temperature and precipitation) to help interpret seasonal burning patterns in documentation or future layers.
- **NASA GIBS** — basemap and contextual imagery for the planned web interface.

## Geographic scope

- **Region of interest:** South Asia.
- **Demonstration area:** Bangladesh (used for examples, baselines, and the first end-to-end prototype we plan to build).

## Note on challenge timeline

Dataset choices, spatial extent, and exact FIRMS product versions may change after the full challenge statement is published on **28 October 2026**. We will update this document when the team locks requirements against the official text.
